# Library Management System

A menu-driven console application built in Python that automates core library operations — issuing, returning, and tracking books, managing student records, and generating reports — all from a single command-line interface.

## Features

- **Book Management** — Add, view, search, sort, update, and delete books
- **Student Management** — Register students and view all student records
- **Issue & Return System** — Issue books with due dates and calculate overdue fines automatically
- **Issue Log** — Track the full history of book issues and returns
- **Categories** — Assign genres/categories to books and filter by category
- **Reports** — View library statistics, a "most issued books" report, and export a full report to a text file
- **Data Persistence** — Save and load book data to/from a text file so data isn't lost between runs

## Concepts Used

- Tuples, lists, and dictionaries
- Functions and control flow (loops, if-else)
- File handling (read/write)
- The `datetime` module for due dates and fine calculation
